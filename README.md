# acui-real-property-storyline

> 一份用于策划地产项目故事线的 AI Skill — 覆盖**住宅 / 办公 / 商业**三大业态，从项目定位到品牌叙事到落地动作的完整方法论。

适用对象：地产策划 / 营销 / 品牌团队、联合办公运营者、商业招商团队、城市更新内容工作者。

---

## 这是什么

这是一份「Agent Skill」—— 一份让 AI 助手按照专业方法论帮你做事的「使用手册」。把它装到你的 AI 工具里（QoderWork / Claude Code / Codex 等），当你说"帮我做某地产项目故事线"时，AI 就会按照里面定义的流程一步步走，不再东拉西扯。

它不是一段普通的 Prompt，也不是一个软件，而是一份结构化的「方法论 + 工作流 + 输出标准」组合。

---

## 它能做什么

输入一个地产项目的基本信息（业态 / 城市 / 板块 / 体量 / 形态 / 开发商 / 客群 / 调性等），输出一份完整的**项目故事线**，包括：

- **策略分析**：城市价值 / 板块基因 / 开发商基因诊断 / **周边竞品矩阵 + 差异化突围** / 双客群洞察 / 国际对标
- **核心传播包**：项目属定 / 定位封号 / Slogan / 案名 / 反传统句式 / 设计哲学 / 内容主力店命名（共用 4 件 + 业态加件 3-4 件）
- **落地动作四模块**：空间体验编排 / 业态组合与品牌矩阵 / 内容策展机制 / 传播节奏排期

支持三种业态独立子流程：

| 业态 | 子流程 | 步骤数 | 特色 |
|---|---|---|---|
| **办公 / 产业园** | A1 - A11 | 11 步 | 5 层递进骨架、产业定位推荐器、高记忆点框架（SMART/三段法） |
| **住宅** | B1 - B9 | 9 步 | 调性锁定优先、产品系基因诊断、场景诗化命名 |
| **商业** | C1 - C11 | 11 步 | 双客群叙事、内容主力店设计器、周边竞品矩阵分析 |

并支持**混合业态大盘**（同时含住宅 + 办公 + 商业的超级综合体）的「母题 + 子线」处理逻辑。

## 快速开始

### 在 QoderWork 中使用（推荐，体验最完整）

直接下载发布页的 `.skill` 文件，拖入 QoderWork 对话窗口，点 "Save skill" 即可。之后说"帮我做地产项目故事线 / 写字楼策划 / 商业故事线"等关键词，会自动触发。

### 在 Claude Code 中使用

```bash
# 下载 .skill 文件（本质是 zip）
mv acui-real-property-storyline.skill acui-real-property-storyline.zip
unzip acui-real-property-storyline.zip

# 放到用户级 skills 目录
mkdir -p ~/.claude/skills
mv acui-real-property-storyline ~/.claude/skills/
```

重启 Claude Code 会话即可。

下载 `SKILL.md` 文件单独保存，需要时让 AI 读取这个文件即可：

```

```

详细多平台安装说明见 [INSTALL.md](./INSTALL.md)。

## 设计理念

这份 skill 在设计上有几条非黑即白的原则：

**1. 方法论 > 案例堆砌**
没有写死任何具体项目案例名（虾龙圩、黄龙万科、朗拾滨屿、玉鸟集等都不在文档里出现）—— 案例会过时，**流程逻辑 + 输出格式 + 判断标准**才耐用。运行时通过联网搜索实时匹配最新对标。

**2. 业态独立 ≠ 方法论割裂**
住宅卖生活向往、办公卖效率与身份、商业卖人货场体验，**叙事内核差异极大**，不能用同一套模板套。所以三套子流程独立设计；但又共享底层的「项目属定 / 定位 / Slogan / 案名」四件套必出项。

**3. 形态 > 体量**
同样是 1-3 万方商业，盒子 Mall 走垂直动线 + 主力店锚定逻辑，街区式走平面动线 + 品牌阵列 + 公共空间逻辑——故事线骨架完全不同。**前置输入清单强制要求把"形态"问清楚再启动子流程**。

**4. 必出项 vs 可选项的判断风格**
不是每个项目都需要的东西（演进史、国际对标、IP形象等）一律设为可选；项目属定 / 定位 / Slogan / 案名永远是必出项不可省。

**5. 故事线交付 = 策略分析 + 传播包 + 落地动作**
策略分析过程本身就是交付物核心组成（呈现"故事为什么成立"的论证链），不是只列结论。

## 输出示例

skill 跑完后会输出一份结构化 Markdown 文档，章节大致包括：

```
一、时代命题与消费趋势锚点
二、板块价值与开发商基因
三、周边竞品矩阵与差异化突围
四、对标洞察
五、双客群洞察（商业）/ 客群命名（住宅 / 办公）
六、调性研判结果
七、反传统叙事（破/立句式）
八、内容主力店设计（商业）/ 产品系迭代叙事（住宅）/ 高记忆点框架（办公）
九、业态组合矩阵 + 品牌阵列（商业）/ 三大场景（住宅）
十、空间设计哲学
十一、核心传播包（共用 4 件 + 业态加件）
十二、落地动作四模块（A 空间 / B 业态 / C 内容 / D 传播）
十三、附录（候选案名 / Slogan / 对标摘要）
```
