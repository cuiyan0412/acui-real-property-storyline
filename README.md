# acui-real-property-storyline

> 一份用于策划不动产项目故事线的 AI Skill — 覆盖**住宅 / 办公 / 商业**三大业态，从项目定位到品牌叙事到落地动作的完整方法论。

适用对象：地产策划 / 营销 / 品牌团队、办公/商业/住宅业态从业者。

---

## 这是什么

这是一份「Agent Skill」—— 一份让 AI 助手按照作者沉淀十年的故事线方法论帮你拆解项目的「使用手册」。把它装到你的 AI 工具里（QoderWork / Claude Code / Codex 等），当你说"帮我做某地产项目故事线"时，AI 就会按照里面定义的流程一步步走，不再东拉西扯。

---

## 什么是故事线（Storyline）

故事线是项目操盘的起手式。在产品尚未成型、营销尚未启动之前，它率先回答一个根本问题：**这个项目凭什么值得被讲述？**

它站在全局视角，完成三件事：向内梳理项目的资源禀赋与价值根基，向外审视市场生态与竞争格局，最终找到那个最锋利的切入角度——然后用一条完整的叙事逻辑，把项目与它的受众连接起来。

**故事线的价值：**

- 为项目的核心价值建立因果链——不只是"我有什么"，而是"为什么此时此地非我不可"
- 在所有产品介绍之前，先给出一个让人想听下去的理由
- 在竞争中锚定身份——不是"我也行"，而是"只有我能扮演这个角色"
- 统摄产品、空间、场景、营销、运营、招商等全部落地动作，让它们生长在同一条逻辑主线上
- 贯穿从拿地到入市到运营的完整周期，确保项目在任何阶段都能一句话讲清自己是谁

---

## 它能做什么

输入一个地产项目的基本信息（业态 / 城市 / 板块 / 体量 / 形态 / 开发商 / 客群 / 调性等），输出一份**可对外讲述、可指导招商、可指导传播、可指导设计落位的项目故事线**，包括：

- **策略分析**：城市价值 / 板块基因 / 开发商基因诊断 / 周边竞品矩阵 / 双客群洞察 / 国际对标
- **核心传播包**：项目属定 / 定位封号 / Slogan / 案名 / 反传统句式 / 设计哲学 / 内容主力店命名（共用 4 件 + 业态加件 3-4 件）
- **落地动作四模块**：空间体验编排 / 业态组合与品牌矩阵 / 内容策展机制 / 传播节奏排期

支持三种业态独立子流程：

| 业态 | 子流程 | 步骤数 | 特色 |
|---|---|---|---|
| **办公 / 产业园** | A1 - A11 | 11 步 | 5 层递进骨架、产业定位推荐器、高记忆点框架（SMART/三段法） |
| **住宅** | B1 - B9 | 9 步 | 调性锁定优先、产品系基因诊断、场景诗化命名 |
| **商业** | C1 - C11 | 11 步 | 双客群叙事、内容主力店设计器、周边竞品矩阵分析 |

并支持**混合业态大盘**（同时含住宅 + 办公 + 商业的超级综合体）的「母题 + 子线」处理逻辑。

## 快速开始

### 在 QoderWork 中使用

直接下载发布页的 `.skill` 文件，拖入 QoderWork 对话窗口，点 "Save skill" 即可。之后说"帮我做地产项目故事线 / 写字楼策划 / 商业故事线"等关键词，会自动触发。

### 在 Claude Code 中使用

```bash
# 下载 .skill 文件（本质是 zip）
mv acui-real-property-storyline.skill acui-real-property-storyline.zip
unzip acui-real-property-storyline.zip

# 放到用户级 skills 目录
mkdir -p ~/.claude/skills
mv acui-real-property-storyline ~/.claude/skills/
```

重启 Claude Code 会话即可。

### 在 Codex CLI 或其他 AI 工具中使用

下载 `SKILL.md` 文件单独保存，需要时让 AI 读取这个文件即可：

```
帮我读取 ~/path/to/SKILL.md，按里面的方法论给我做某地产项目的故事线
```

详细多平台安装说明见 [INSTALL.md](./INSTALL.md)。

## 输出示例

skill 跑完后会输出一份结构化 Markdown 文档，章节大致包括：

```
一、时代命题与消费趋势锚点
二、板块价值与开发商基因
三、周边竞品矩阵与差异化突围
四、对标洞察
五、双客群洞察（商业）/ 客群命名（住宅 / 办公）
六、调性研判结果
七、反传统叙事（破/立句式）
八、内容主力店设计（商业）/ 产品系迭代叙事（住宅）/ 高记忆点框架（办公）
九、业态组合矩阵 + 品牌阵列（商业）/ 三大场景（住宅）
十、空间设计哲学
十一、核心传播包（共用 4 件 + 业态加件）
十二、落地动作四模块（A 空间 / B 业态 / C 内容 / D 传播）
十三、附录（候选案名 / Slogan / 对标摘要）
```
